# Mikaela VPN — расширение для Chrome

Бесплатное расширение: включает прокси серверов Mikaela VPN в одно нажатие, сам выбирает самый быстрый сервер
и рекламирует приложения и бота ([кабинет](https://cabinet.mikaelavpn.xyz/), [Telegram-бот](https://t.me/vpnmikaelabot)).

## Что здесь
| Путь | Что это |
|---|---|
| `extension/` | исходники расширения (Manifest V3) |
| `servers.json` | список серверов. Его **сам обновляет бот** после настройки сервера |
| `store/` | скриншоты и промо-плитки для Chrome Web Store (ru/en) |
| `STORE.md` | тексты для карточки магазина, обоснования разрешений, ответы на вопросы формы |
| `PRIVACY.md` | политика конфиденциальности (ссылка на неё указана в магазине) |
| `SERVER.md` | как настроить HTTPS-прокси на сервере вручную |
| `.github/workflows/build.yml` | автосборка ZIP |

## Автосборка
При каждом изменении `extension/**`, `servers.json` или `store/**` GitHub Actions собирает ZIP и обновляет релиз
[latest](../../releases/latest). Собирать вручную ничего не нужно:
- `mikaela-vpn-chrome.zip` — загружать в Chrome Web Store (в него автоматически кладётся актуальный `servers.json`);
- `store-assets.zip` — скриншоты и промо-плитки для карточки.

Ссылка на последнюю сборку не меняется:
`https://github.com/tneange1/Mikaela-VPN-Chrome-Extension/releases/latest/download/mikaela-vpn-chrome.zip`

## Как это работает со списком серверов
Расширение раз в 6 часов скачивает `servers.json` из этого репозитория (только данные, не код — это разрешено правилами
магазина). Поэтому новые серверы появляются у пользователей **без новой проверки в магазине**: достаточно, чтобы бот
дописал сервер сюда. Сам код расширения обновляется только через магазин: измените `extension/` и **поднимите `version`
в `extension/manifest.json`** (магазин не принимает ту же версию дважды), затем загрузите свежий ZIP из Releases.

## Правила магазина
Единственное назначение, обоснования разрешений и данные для формы приватности — в `STORE.md`. VPN- и прокси-расширения
проверяют дольше обычных. Для первой проверки в ZIP должен быть хотя бы один рабочий сервер (автосборка не даст выпустить
ZIP с заглушками).

Версия для Firefox: https://github.com/tneange1/Mikaela-VPN-Extension-FireFox (список серверов берёт отсюда).
